3) Для реализации консольного чата реализована простая объектно-ориентированная структура на C++ с использованием классов. 
Приложение работает в консоли и предоставляет пользователю пошаговое меню для регистрации, входа в систему, 
отправки сообщений (всем или конкретному пользователю), просмотра сообщений и списка пользователей.

4) Классы: 
Класс User - Хранит логин, пароль и имя пользователя. Используется для идентификации и авторизации.
Класс Message - Хранит отправителя, получателя и текст сообщения.
Класс Chat - Управляет списком пользователей, сообщениями, текущим пользователем и реализует всю логику.
Класс ChatException - Класс для обработки ошибок и исключительных ситуаций.
   Функции:
registerUser(логин, пароль, имя) — регистрация нового пользователя, возвращает true/false.
login(логин, пароль) — вход пользователя, возвращает true/false.
logout() — выход пользователя из системы.
sendMessage(получатель, текст) — отправка сообщения (получатель пуст — всем, иначе личное).
showMessages() — выводит все сообщения, относящиеся к текущему пользователю.
showUsers() — выводит список всех зарегистрированных пользователей.
isLoggedIn() — проверяет, авторизован ли пользователь.
getCurrentUserName() — возвращает имя текущего пользователя.
